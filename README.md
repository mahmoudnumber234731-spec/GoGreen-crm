# GoGreen CRM — دليل التشغيل

## الملفات
- `index.html` — صفحة تسجيل الدخول (بهوية GoGreen)
- `dashboard.html` — الصفحة الرئيسية: الأقسام + لوحة أونلاين/أوفلاين (للأدمن)
- `profile.html` — إعدادات الحساب: تغيير اليوزرنيم، الباسورد، الصورة الشخصية
- `config.js` — بيانات الاتصال بـ Supabase (مشتركة بين كل الصفحات)
- `schema.sql` — كل جداول وقواعد الحماية الخاصة بقاعدة البيانات

## خطوات التركيب

### 1. قاعدة البيانات
افتح Supabase Dashboard → **SQL Editor** → New query، الصق محتوى `schema.sql` بالكامل واضغط Run.

### 2. رفع الملفات على GitHub
ارفع كل الملفات دي في نفس المجلد (root) بتاع الريبو المربوط بـ Vercel، بحيث الروابط النسبية بين الصفحات تشتغل صح.

### 3. أول حساب أدمن
Supabase مفيش فيها صفحة "تسجيل" حاليًا بشكل مقصود (الحسابات تتعمل من إدارة النظام فقط، كإجراء أمان). عشان تعمل أول مستخدم:
1. Supabase Dashboard → **Authentication → Users → Add user** → حط الإيميل والباسورد.
2. Table Editor → جدول `profiles` → هتلاقي صف اتعمل تلقائي لنفس المستخدم.
3. غيّر عمود `role` من `employee` لـ `admin`.
4. سجّل دخول من `index.html` بنفس الإيميل والباسورد.

لإضافة موظفين جدد بعد كده: نفس الخطوة (Add user من الداشبورد) — البروفايل بتاعهم بيتعمل تلقائي بصلاحية "employee".

### 4. الشعار (اللوجو)
الصفحة حاليًا مبنية بشعار نصي (🌱 GoGreen). لو عندك لوجو جاهز كصورة:
- ارفعه باسم `logo.png` في نفس المجلد
- في `index.html` استبدل الـ `<div class="glyph">🌱</div>` بـ `<img src="logo.png" style="width:44px;height:44px;border-radius:12px;">`

### 5. الأقسام (Departments)
- الأدمن بس هو اللي بيشوف زرار "إضافة قسم جديد" في الداشبورد.
- كل قسم دلوقتي هو "بطاقة" فاضية جاهزة تتربط بصفحة/جدول خاص بيه — القسم المالي متعمل بالفعل كبداية.
- لما تحدد إيه محتوى كل قسم (عملاء، فواتير، مخزون...) أقدر أبني لك صفحة مخصصة لكل قسم تتفتح لما يدوس عليه.

### 6. نظام أونلاين/أوفلاين
كل مستخدم داخل النظام بيبعت "نبضة" لقاعدة البيانات كل 20 ثانية. لو آخر نبضة كانت من أقل من دقيقة، بيظهر أونلاين. اللوحة دي بتظهر للأدمن بس في الداشبورد.

## اقتراحات لمرحلة تالية
- **صلاحيات أدق لكل قسم**: مثلاً موظف المبيعات يشوف قسمه بس، والأدمن يشوف الكل.
- **سجل نشاط (Activity Log)**: تسجيل كل عملية إضافة/تعديل لأي بيانات مهمة (مفيد جدًا في CRM).
- **صفحة "نسيت كلمة المرور"** باستخدام `supabase.auth.resetPasswordForEmail`.
- **دومين مخصص** بدل رابط Vercel الافتراضي، يديلك شكل احترافي أكتر (مثلاً crm.gogreen.com).
